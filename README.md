# python-math
repo with math equations done in python

# How to run it?

Install any of the chosen python files and run ```pip install requirements.txt``` to install
the required modules.

# What does it do?
This is a repo to show the capabilities of python and to test out the math functions it has.

# How this works?
It is famous equations that are available online and are turned into outputs for
testing or creating stuff.
